# Data

This directory contains small, non-sensitive sample data and runtime placeholders.

## Rules

Only include audio/data that:

- You created yourself, or
- You have explicit permission to redistribute, and
- Has a license compatible with this repository.

Never commit:

- Private calls
- Personal recordings
- Customer data
- OTPs
- Financial information
- Personally identifiable information
- Unlicensed datasets

## Runtime data

`data/live/` is intended for local runtime status/log files and is ignored by Git.

A `.gitkeep` file may be used to preserve the directory structure.
