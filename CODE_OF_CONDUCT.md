# Code of Conduct

## Our commitment

SwaraShield is a community project. We want contributions to be respectful, constructive, technically useful, and welcoming to people with different experience levels.

## Expected behavior

Participants should:

- Be respectful.
- Give constructive feedback.
- Focus criticism on ideas and implementation, not people.
- Assume good faith while asking for evidence.
- Respect privacy and consent.
- Keep security discussions responsible.
- Help new contributors learn.

## Unacceptable behavior

The following is not acceptable:

- Harassment
- Personal attacks
- Hate speech
- Threats
- Doxxing
- Publishing private information
- Malicious disclosure of secrets
- Deliberately submitting harmful code
- Using project infrastructure to attack others

## Security issues

Do not publicly disclose sensitive vulnerabilities before maintainers have had an opportunity to investigate. Follow `SECURITY.md`.

## Enforcement

Maintainers may remove comments, reject contributions, or restrict participation when necessary to keep the project safe and constructive.

For project-specific enforcement questions, open a private contact with the maintainers listed in the repository.
